# DEW Temp Cleaner

A lightweight open-source temporary file cleaner for Windows 10 and Windows 11.

## Features

- Clean user temporary files
- Clean Windows temporary files
- Skip files currently in use
- Skip protected files
- Display deleted file count
- Display freed disk space
- Progress indicator
- Cancel operation
- Administrator support
- No internet connection required

## Supported Systems

- Windows 10 x64
- Windows 11 x64

## Download

Download the latest version from:

Releases:
https://github.com/Dewmina-Senewirathna/DewTempCleaner/releases/latest

## Installation

Download the latest EXE and run it.

Administrator permission is required because Windows Temp can contain
protected files.
